# Episode 3 — "Ali va IELTS Reading: Vaqt qayerga ketdi?!"

1080×1920 · 30 fps · 52.3 s · composition `Ep03AliReading`, thumbnail still `Ep03Thumbnail`.

## Files
- `script.json` — the single source of truth: lines, voice, highlight words, scene membership.
- `timing.json` — generated by `scripts/episode_voice.py` (clip durations + word timings from forced alignment).
- `timeline.ts` — builds scene/line/word frame timings from the two files above.
- `composition.tsx` — scenes, transitions, subtitles, narration, ducked music.
- `scenes/S1Hook … S8Ending.tsx`, shared props in `scenes/common.tsx`.
- `thumbnail/Ep03Thumbnail.tsx`.
- Audio: raw VoiceLab clips `public/ep03/vo_raw/`, processed clips `public/ep03/vo/`, SFX/music `public/audio/norm/`.

## Voice (VoiceLab, voice "Javohir — Bright Presenter", id in `script.json`)
Generation IDs are cached in `voicelab_generations.json`. **l15b and l17 are still placeholders** (VoiceLab credits ran out):
the captions run on estimated timing and no voice plays there.

To finish them:
1. Generate the two lines with the same voice in VoiceLab (text is in `script.json`).
2. Save the WAVs as `public/ep03/vo_raw/l15b.wav` and `public/ep03/vo_raw/l17.wav`, record the IDs in `voicelab_generations.json`.
3. `python3 scripts/episode_voice.py ep03` (trims, normalises to −17 LUFS, aligns words, rewrites `timing.json`).
4. Re-render (below). Scenes re-time automatically.

## Render
```bash
npx remotion render src/index.ts Ep03AliReading out/ep03_raw.mp4 --codec=h264 --crf=18 --audio-bitrate=320k
# master: linear gain to −16 LUFS, true peak ≤ −1.5 dBTP (2-pass loudnorm, see below)
ffmpeg -i out/ep03_raw.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=20:print_format=json -f null -   # pass 1: read measured_* values
ffmpeg -i out/ep03_raw.mp4 -c:v copy -af "loudnorm=I=-16:TP=-1.5:LRA=20:measured_I=…:measured_TP=…:measured_LRA=…:measured_thresh=…:offset=…:linear=true,aresample=48000" -c:a aac -b:a 320k -movflags +faststart output/ep03_ali_reading.mp4
npx remotion still src/index.ts Ep03Thumbnail output/ep03_thumbnail.png
```

## Mix check (stems)
```bash
for s in voice fx music all; do npx remotion render src/index.ts Ep03AliReading out/stems/$s.wav --codec=wav --props="{\"stem\":\"$s\"}"; done
python3 scripts/measure_mix.py out/stems <timeline json with absolute line starts>
```
Ducking rules live in `MIX` in `src/audio/EpisodeAudio.tsx` (music −25 dB / SFX −14 dB under speech).
